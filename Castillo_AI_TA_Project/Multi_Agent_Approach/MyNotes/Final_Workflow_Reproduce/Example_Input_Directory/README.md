# Example `Input/`

This is a real, complete example of what belongs in the `Input/` folder you
create per `Directory_Creation.pdf`: exactly one source PDF, one lecture.

`Lecture-scattering-Hamiltonian_241022-forward.pdf` is a handwritten/board
lecture on scattering by a central potential and the Hamiltonian (HC 6001,
22 October 2024). It is the source this kit's pipeline turned into the
tagged, accessible document in `../Example_Deliverable_Directory/` — so you
can open both side by side and see exactly what the agent is expected to
do to a file like this one.

When you run this yourself, replace this file with your own lecture PDF(s)
— one per file, however many lectures you have. Nothing else goes in this
folder.
