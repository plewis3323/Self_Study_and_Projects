## Q & A captured so far
- Handler / `StreamHandler` / `addHandler` in plain terms (logger makes the message, handler delivers it, `addHandler` connects them; stdout vs. stderr; `FileHandler`; multiple handlers; follow-up: `addHandler` is one-time setup, not the sending step; bridge mental model) — 11/9/26
- `__name__` is a dunder *variable* (module name string, `"__main__"` when run directly), not a method; `getLogger` creates the logger — 11/9/26
- `try`/`except` = exception handling, not a conditional (`if` checks first; `try` runs and catches errors; ties to `division()`'s `except ValueError`) — 11/12/26
- Dunders in general = Python's reserved hooks: attributes Python fills in (`__name__`, `__file__`, `__doc__`) + methods Python calls for normal syntax (`__init__`, `__str__`, `__len__`, `__add__`, `__eq__`); `Point` example — 11/12/26
- Module vs. class: package (folder) > module (.py file) > class/function/variable > method/attribute; `logging.StreamHandler(...)` = module.class — 11/12/26
- `FileHandler` can write to `.txt` too; output is plain text either way, `.log` is just the convention; creates the file if missing, appends if present — 11/12/26
- C++ equivalent: no std logging (only `cout`/`cerr`/`clog`); libraries spdlog (sinks = handlers), glog, Boost.Log; ROOT's `Info`/`Warning`/`Error`/`Fatal` + `gErrorIgnoreLevel` ≈ `setLevel` — 11/12/26
